# John Trust Open Publishing

Production website source for **The John Trust Open Publishing**, intended for `open.johntrust.org`.

## Structure
- `index.html` — organization landing page
- `privacy.html` — starter privacy policy
- `assets/css/style.css` — responsive visual system
- `assets/js/app.js` — publication data, search, newsletter placeholder

## Deployment
Designed as a static site suitable for GitHub Pages. Add the custom domain `open.johntrust.org` after Pages is enabled and DNS is configured.
